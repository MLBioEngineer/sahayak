Project: সহায়ক (Sahayak)

Bengali Medical AI Chatbot & IoT-Driven Real-Time Sleep Apnea Detection System
Official Technical Specification & Presentation Deck Companion

Executive Pitch: Sahayak is an affordable (~$25 USD) edge-IoT healthcare system that continuously acquires single-lead ECG biopotential signals at 100 Hz, detects Obstructive Sleep Apnea (OSA) using a hybrid 1D-CNN + BiLSTM + Attention deep neural network (84.1% accuracy), provides non-linear 2D Poincaré HRV analytics, and delivers native Bengali conversational triage via a self-hosted open-weights LLM.

2. Embedded Firmware & IoT Stack

  • Sampling Frequency: 100 Hz (10,000 μs hardware micros loop).
  • Digital Signal Processing: On-device 50 Hz digital notch filter (eliminates AC mains hum) and moving-average thoracic baseline wander correction.
  • Transmission Protocol: HTTP/REST streaming with 100-sample batches (1-second packets) to optimize memory buffer and prevent lwIP socket fragmentation.

3. Machine Learning & Deep Neural Network Pipeline

  • Validated Dataset: PhysioNet Apnea-ECG Database (continuous 100 Hz single-lead overnight PSG recordings from 35 subjects).
  • Architecture:
    1. 1D-CNN: Extracts local morphological QRS, P, and T-wave features (Conv1d → BatchNorm → GELU → MaxPool).
    2. Bidirectional LSTM (BiLSTM): Tracks long-term temporal dependencies, capturing cyclical bradycardia-tachycardia patterns across epochs.
    3. Self-Attention Layer: Dynamically pools features focusing on respiratory collapse episodes.
    4. Dense Classifier: Softmax outputting binary Apnea vs Normal classification.
  • Subject-Wise Accuracy: 84.1%
  • Explainable AI (XAI): 1D-GradCAM attention saliency maps showing clinicians the exact seconds that prompted the diagnosis.

4. Biomedical Signal Processing & Non-Linear HRV Analysis

  • Time-Domain Metrics: Heart Rate (BPM), RR Interval (ms), HRV RMSSD (parasympathetic vagal tone), SDNN.
  • ECG-Derived Respiration (EDR): Derived from QRS complex area and R-peak height modulation.
  • 2D Poincaré Scatter Plot (RRn vs RRn+1):
    • SD1: Short-term beat-to-beat variability (vagal parasympathetic tone).
    • SD2: Long-term variability (sympathetic + vagal tone).
    • SD1/SD2 Ratio: Sympathovagal balance index.
    • Fitted autonomic ellipse rotated -45° along the identity line (y = x).
  • 5-Second Breath-Hold Demonstration: Enables live demonstration of physiological cardiac pauses during voluntary breath cessation.
